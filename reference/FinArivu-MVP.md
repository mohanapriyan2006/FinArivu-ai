
# 📱 MVP.md — FinArivu AI React Native Frontend Blueprint

## 1. Product & Architecture Overview
FinArivu AI is a mobile-first, multi-agent AI Personal CFO built for Indian Salaried Professionals.

### Key Constraints & Technical Stack
- **Framework:** React Native (Expo SDK 51+ with TypeScript)
- **Styling:** Pure React Native `StyleSheet` with central `ThemeContext` (NO Tailwind CSS)
- **Navigation:** React Navigation v6 (Bottom Tabs + Native Stack)
- **State & Data Fetching:** React Context + TanStack React Query v5
- **Charts & Visualization:** `react-native-svg` + `victory-native`
- **Security:** `expo-secure-store` for Auth Tokens, local biometrics

## 3. Directory Structure

```text
src/
├── assets/             # Icons, animations (Lottie), images
├── components/         # Reusable presentation-only UI components
│   ├── common/         # Buttons, Cards, Inputs, Typography, Modals
│   ├── charts/         # Net Worth Chart, Pacing Bars, Gauge Meters
│   └── artifacts/      # Native UI cards generated by AI Copilot
├── contexts/           # AuthContext, FinancialContext, ThemeContext
├── engines/            # Frontend calculation wrappers (display-only math)
├── features/           # Feature modules (UI screens + local components)
│   ├── home/
│   ├── pulse/
│   ├── copilot/
│   ├── insights/
│   └── hub/
├── hooks/              # Custom reusable React hooks (e.g. useFinancialData)
├── navigation/         # Navigation containers and type definitions
├── services/           # API service modules (Axios / Fetch wrappers)
├── theme/              # Design tokens and ThemeProvider
├── types/              # TypeScript interfaces and API schemas
└── utils/              # Currency formatters (INR ₹), date utilities

```

## 4. Phase 1 MVP Frontend Build Order

1. **Core Setup:** `ThemeContext`, Typography, Base Layouts, `ThemedView`, `ThemedText`.
2. **Navigation Shell:** `MainTabNavigator` with 5 Bottom Tabs & Icons.
3. **Authentication & Profile:** `AuthContext` + Integration with SecureStore.
4. **Home Screen:** Net Worth Card, Asset/Liability Lists, Historical Area Chart.
5. **Pulse Screen:** Income vs Expense Pacing Bar, Budget Progress Rings, Goal Cards.
6. **AI Copilot Screen:** Floating Prompt Bar, Message List, Dynamic Native Artifact Renderer (Tax/Budget Cards).
7. **Insights Screen:** Financial Health Score Gauge (0-100), Priority AI Recommendation Feed.
8. **Hub Screen:** Settings list, Risk Profile Toggle, Security Settings.
